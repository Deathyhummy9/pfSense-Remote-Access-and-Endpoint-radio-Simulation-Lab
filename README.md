<h1 align="center">pfSense and OpenVPN Remote Access + Endpoint Simulation Lab</h1>

This project demonstrates how to configure pfSense as an OpenVPN server and securely connect a remote Linux client to a protected LAN.  
It also simulates a real-world endpoint device (such as a radio, camera, or on-site server) accessible only through the VPN.  
This setup showcases networking, firewall, routing, and remote access fundamentals—core skills for IT Support, SysAdmin, and Network Engineering roles.

##  Environments and Technologies Used

- **pfSense 2.7.1**
- **VirtualBox 7.0**
- **Linux Mint 21.2** (Client + Endpoint)
- **OpenVPN 2.6.x**

---

##  Operating Systems Used
- pfSense (Firewall + VPN Gateway)
- Linux Mint (Client / Endpoint Simulation


##  Prerequisites

- pfSense ISO installed in VirtualBox  
- Two Linux Mint VMs configured (Client & Endpoint)  
- OpenVPN client installed on Linux  
- pfSense firewall and LAN configured  
- Internet connectivity verified
